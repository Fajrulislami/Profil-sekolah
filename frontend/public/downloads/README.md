# 📁 Folder: public/downloads/

Folder ini digunakan untuk menyimpan file PDF persyaratan PPDB yang dapat diunduh langsung oleh calon wali murid dari halaman `/ppdb`.

---

## 📋 Daftar File PDF yang Perlu Ditempatkan di Sini:

| Nama File | Keterangan |
|:---|:---|
| `syarat-ppdb-tk.pdf` | Brosur & syarat pendaftaran Jenjang TK |
| `syarat-ppdb-sd.pdf` | Brosur & syarat pendaftaran Jenjang SD |
| `syarat-ppdb-smp.pdf` | Brosur & syarat pendaftaran Jenjang SMP |
| `syarat-ppdb-pesantren.pdf` | Brosur & syarat pendaftaran Jenjang Pesantren Rabbani |

---

## ✅ Cara Mengganti atau Memperbarui File PDF:

1. Buat file PDF baru (misalnya menggunakan Canva, Word, atau Adobe).
2. Simpan dengan **nama file yang sama persis** seperti tabel di atas (huruf kecil semua, tanpa spasi).
3. Letakkan file PDF baru di folder ini (`public/downloads/`), gantikan file lama.
4. File langsung bisa diunduh dari website tanpa perlu restart server atau deploy ulang (jika sudah di production).

---

Setelah file PDF ditempatkan di sini, URL unduhan akan otomatis tersedia di:
